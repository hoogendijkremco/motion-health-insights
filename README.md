# Motion Health Insights

Maak een header voor een maandelijkse online nieuwsbrief getiteld: Fast Movers top 10 zorg dat in het ontwerp het thema gezondheidszorg gericht op het bewegingsapparaat wordt meegenomen dus orthopedie, revalidatiegeneeskunde, reumatologie, farmacie en artrose. maak een kleurrijk ontwerp met een moderne, optimistische en innovatieve uitstraling. zorg dat de header kan meeschalen met het apparaat waarop de nieuwsbrief wordt gelezen
